Samsung
  1. 打开 Settings（设置）。
  2. 进入 Connections。
  3. 选择 Mobile networks。
  4. 点击 Access Point Names。
  5. 点击右上角 Add，按照左边资料填写。
  6. 保存并选择 TuneTalk APN，然后关闭再开启移动数据。
OPPO / realme
  1. 打开 Settings（设置）。
  2. 进入 Mobile network。
  3. 选择正在使用的 TuneTalk SIM。
  4. 点击 Access point names。
  5. 点击右上角的 +，按照左边资料填写。
  6. 保存并选择 TuneTalk APN，然后关闭再开启移动数据。
vivo / iQOO
  1. 打开 Settings（设置）。
  2. 进入 Mobile network。
  3. 选择 TuneTalk SIM。
  4. 点击 Access point name (APN)。
  5. 建立新的 APN，并按照左边资料填写。
  6. 保存并选择 TuneTalk APN，然后关闭再开启移动数据。
HONOR / HUAWEI
  1. 打开 Settings（设置）。
  2. 进入 Mobile network。
  3. 选择 Mobile data。
  4. 点击 Access Point Names (APNs)。
  5. 点击 + 建立 APN，并按照左边资料填写。
  6. 保存并选择 TuneTalk APN，然后关闭再开启移动数据。
iPhone
  1. 打开 Settings（设置）。
  2. 进入 Mobile Service / Cellular。
  3. 点击 Mobile Data Network。
  4. 在 Mobile Data 的 APN 输入 tunetalk。
  5. 返回上一页，然后关闭再开启移动数据。
